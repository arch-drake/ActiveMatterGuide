# Active Matter Source Atlas alpha/v2.2.0-alpha.1

This branch is the public alpha source candidate for the 13-region raster map experience, Gigastructure floor-only workspace, link fixes and local bundle tooling.

**Download the entire candidate snapshot:** https://github.com/arch-drake/ActiveMatterGuide/archive/refs/heads/alpha/v2.2.0-alpha.1.zip

After extraction, open index.html in Chrome/Edge, then Explore Source Atlas. Third-party tiles need an explicit opt-in.

**Formal GitHub prerelease is NOT assured merely because this branch exists.** It is created by .github/workflows/publish-alpha.yml only if the GitHub Actions runner and permissions work. Check https://github.com/arch-drake/ActiveMatterGuide/releases for the real publication state.

The separate bundled 2.1.1 offline guide still contains older illustrations and candidate pins; the new atlas does not overlay unaligned markers. Gigastructure is not a completed flat map. No real building heights are certified.
