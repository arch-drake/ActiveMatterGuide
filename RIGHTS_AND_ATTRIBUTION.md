# Rights, provenance and attribution

This is an independent, unofficial fan guide for Active Matter. It is neither affiliated with nor endorsed by the game's developers or publisher. Names, trademarks and original game content belong to their respective rights holders.

The original illustrations and synthesized music supplied with this guide are not representations of official game assets. The music permission statement is in `docs/ORIGINAL_AUDIO_PERMISSIONS.md`. Community marker coordinates are attributed to the reference links documented in `docs/MAP_PROVENANCE_AND_ACCURACY.md`. Some datasets have no explicit redistribution grant, so this project **does not** bundle full third-party map packs or unlicensed in-game screenshots.

**Source code license:** not selected yet. Making the repository public does not automatically put all source code or assets under an open-source license. Do not add an MIT/Apache/CC license across all content until the project owner confirms the intended permissions and third-party constraints are reviewed.

**Contributing:** only submit material you made, have permission to distribute, or can reference by a public link rather than copying. Verify map/geography and marker artwork against rights-cleared game screenshots before describing them as game-exact.
