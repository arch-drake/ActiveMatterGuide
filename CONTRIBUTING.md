# Contributing

Thanks for helping improve Active Matter // Field Operations.

Start with an Issue describing the problem. Include the map, game version, raid variant (Isolated/Open; Solo/Squad), steps to reproduce, expected/actual behavior, and the source of any game-specific fact.

- Prefer small, reversible patches. Keep layers separated: core, storage, services, feature modules and view layer.
- Protect all established local storage keys. Changes must not erase player progress.
- Run syntax, browser interaction, data validation and backup tests before suggesting a release.
- Distinguish official evidence, community reports and unknown mechanics.
- Do not claim illustrated backgrounds are exact game geography or use unlicensed textures.
- Don't submit game files, private account data, saved browser backups or copyrighted recordings.

The maintainer reviews rights and mechanics before accepting additions. A general open-source license has not yet been selected; submitting a contribution does not authorize reuse of third-party intellectual property.
