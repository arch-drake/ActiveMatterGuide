## Contributor procedure
When adding a reference URL, verify it opens a page showing the named location, record access date, mode/build, provenance and license/redistribution terms. Link to the source if copies cannot be lawfully republished. Combine corroborated details rather than reproducing a site's large proprietary dataset.
